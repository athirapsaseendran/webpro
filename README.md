# Responsive Personal Portfolio Website

A responsive personal portfolio website created using HTML5 and CSS3.

## 📌 About the Project

This project is a simple three-page personal portfolio website designed to showcase personal information, projects, and contact details.

The website is responsive and works on both desktop and mobile screen sizes.

## 📄 Pages

### 1. Home
- Personal introduction
- Name
- Photo placeholder
- Short tagline
- Button to view projects

### 2. Projects
- Displays personal projects
- Uses CSS Grid for the project cards
- Contains a minimum of three projects

### 3. Contact
- Contact form
- Name field
- Email field
- Message field
- Uses Flexbox for styling
- No backend is required

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries
